JAMES LENNOX — WEB DESIGN & DEVELOPMENT PORTFOLIO

This site is based on the supplied INFO1005 Marge Simpson multipage template structure and its completed example. It has been substantially rebranded and rebuilt for James's web design/development career direction.

PAGES
- index.html: Home / introduction
- about.html: About and design approach
- resume.html: Education, project experience, developing skills and PDF link
- portfolio.html: Project gallery with Bootstrap modal lightbox
- contact.html: Contact information area and client-side demo form

TECHNOLOGY
- Bootstrap 5.3.3 via CDN
- Custom CSS and responsive breakpoints
- Semantic HTML5
- Bootstrap Icons
- Google Fonts: Space Grotesk (headings) and DM Sans (body)
- JavaScript: theme switch, typewriter, lightbox and form validation
